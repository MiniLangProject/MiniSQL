# Development history

`DEVELOPMENT_CHANGELOG.md` preserves the detailed package and repair-candidate
history from the iterative M0-M50 development process. It is retained for
traceability but is not the concise release changelog shown at repository root.

The clean repository intentionally omits the many per-run failure narratives.
The accepted architecture decisions are preserved in `docs/adr/`, and the final
106-phase evidence is preserved in `docs/acceptance/`.

Milestone-level acceptance definitions are preserved in `milestones/`.
