# M26 acceptance candidate — offline page-size migration

M26 performs a source-preserving logical rewrite into a separate target with a
new frozen page size. It transfers schema/security state, rows and LOBs,
rebuilds indexes, verifies the target, and publishes it only after successful
validation. The legacy in-place command remains fail-closed.

A failed attempt can leave an unpublished uniquely named staging directory for
diagnosis; it does not modify or replace the source. M26 is accepted only by
the cumulative Windows SUCCESS gate.
