# M12 acceptance — SQL lexer, parser and AST

Status: **accepted** by `MiniSQL_M11_M15_RESULTS_20260726-143135.zip`. The cumulative
Windows run passed phase 31 after every lower milestone regression.

M12 covers token positions, comments, quoted identifiers, escaped string literals,
numeric literals, operators and multi-statement parsing. The grammar test exercises
CREATE TABLE/INDEX, INSERT, UPDATE, DELETE, SELECT, BEGIN, COMMIT and ROLLBACK plus
constraints, identity columns, aliases, predicates, ORDER BY, LIMIT and OFFSET.
Malformed SQL, unterminated strings and empty table definitions return the stable SQL
syntax error rather than crash or silently accept partial input. R1 reruns it unchanged.
