# M4 acceptance contract

Status: **accepted by the cumulative M2–M5R2 Windows result (19/19 phases PASS)**.

Acceptance is performed by the single cumulative `test.ps1` M0-M5 gate.

M4 introduces page format v1, redundant 4096-byte superblocks and paged files. A paged
file stores two independently checksummed metadata generations at offsets 0 and 4096;
page data starts at offset 8192.

Acceptance includes all earlier gates and requires:

- independent page-header and payload corruption detection;
- superblock encode/decode and generation ordering;
- persisted page size, file identity, database identity and page count;
- reopen without consulting mutable global defaults;
- removal of an uncommitted tail after interrupted metadata publication;
- fallback to the older valid superblock when the newest copy is corrupt;
- refusal when both superblocks are corrupt; and
- the cumulative result marking M4 `PASS`, exit code 0 and final line `MiniSQL M2-M5 acceptance test: SUCCESS`.
