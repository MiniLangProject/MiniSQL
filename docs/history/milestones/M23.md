# M23 acceptance candidate — index integration

M23 integrates persistent B+ trees with DML, equality/range/composite seeks,
indexed equality joins, EXPLAIN output, consistency checking, and durable
repair through `catalog/indexes.dirty`.

The heap plus committed WAL remain authoritative. Indexes are repairable
derived state and are rebuilt after committed heap changes in this milestone.
M23 is accepted only by the cumulative Windows SUCCESS gate.
