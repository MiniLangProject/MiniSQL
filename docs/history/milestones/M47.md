# M47 candidate — TLS 1.3 and X.509

M47 provides a standards-compatible TLS 1.3/X.509 transport terminator written
with the Python standard library. The server-side process accepts TLS and
forwards only to a loopback MiniSQL server; the client-side process exposes only
a loopback plaintext port and verifies the remote certificate and hostname.
The core MiniLang wire protocol remains unchanged.
