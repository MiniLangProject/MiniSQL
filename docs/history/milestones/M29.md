# M29 — Authenticated encrypted transport

Status in this archive: **acceptance candidate**.

Directional AES-256-GCM frame protection, sequence replay protection,
fail-closed plaintext rejection and remote binding only through authenticated
secure mode. This is not TLS.

The R2 Windows run passed eleven of twelve direct M29 checks but failed a
package-unsafe concrete-type-name assertion before the encrypted process test.
R3 uses the package predicate `uuid.isAeadPacket`. M29 is accepted only when the
cumulative R3 Windows gate records `PASS` for both M29 phases.
