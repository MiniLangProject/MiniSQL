# M24 acceptance candidate — ALTER TABLE and schema evolution

M24 covers metadata-only `ADD COLUMN`, column/table rename, and transactional
add/drop of CHECK, PRIMARY KEY, UNIQUE, and FOREIGN KEY constraints. Existing
rows are decoded against compatible schema prefixes and materialize persisted
defaults for newly appended columns.

Physical `DROP COLUMN` and type rewrites remain outside this milestone. M24 is
accepted only by the cumulative Windows SUCCESS gate.
