# M1 initial candidate acceptance status

The initial M1 candidate (`0.1.0-m1`) is **not accepted**.

The Windows acceptance archive `MiniSQL_M1_RESULTS_20260725-223814.zip` reported:

```text
phases 1-7: PASS
phase 8: FAIL
status: FAIL
```

Compilation and all M0 regressions succeeded. Execution of the M1 golden-vector
program exposed an invalid assumption in the signed-I64 implementation: native
MiniLang integers do not carry the complete signed 64-bit domain.

The candidate is superseded by **M1R1**. Its full diagnostic record is preserved in
`M1_FAILURE_20260725.md`. M1 remains open until the M1R1 acceptance suite exits with
code `0` and prints its required success line.
