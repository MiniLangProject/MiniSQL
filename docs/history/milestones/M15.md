# M15 acceptance candidate — basic SQL execution

M15 provides the first executable SQL engine: INSERT, UPDATE, DELETE and single-table
SELECT with filtering, projection, aliases, DISTINCT, ordering and LIMIT/OFFSET. It
supports autocommit and explicit BEGIN/COMMIT/ROLLBACK, read-your-writes, read-only
transactions, identity/default values and immediate NOT NULL, CHECK, PRIMARY KEY,
UNIQUE and FOREIGN KEY checks.

The acceptance workload creates a schema through SQL, mutates and queries rows, checks
constraint failures and failed-transaction state, rolls back and commits explicit
transactions, closes the database and verifies all committed results after recovery and
reopen. Joins, aggregates and costed plans intentionally begin at M16-M17.
