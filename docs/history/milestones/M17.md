# M17 acceptance candidate

M17 adds CRC-protected persistent table/column statistics, ANALYZE, deterministic integer
cost estimates, logical/physical plan rendering, EXPLAIN and EXPLAIN ANALYZE. Statistics
must survive reopen and corruption must be rejected.

R1 additionally verifies that loading an existing `statistics.tbl` returns the concrete
`StatisticsCatalog` type. Internal decoding uses `decodeCatalog`; only qualified external
callers use the compatibility API `statistics.decode`.
