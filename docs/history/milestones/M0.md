# M0 acceptance procedure

From a Windows PowerShell prompt in the project root:

```powershell
.\test.ps1 -Compiler C:\path\to\mlc_win64.py
```

Expected high-level phases:

1. repository manifest
2. specification/config validation
3. MiniLang package/path validation
4. server compile and self-test
5. client compile and self-test
6. maintenance tool compile and self-tests
7. all-module smoke compile and run
8. final gate

The final line must be:

```text
MiniSQL M0 acceptance test: SUCCESS
```

Send the generated `build/MiniSQL_M0_RESULTS_<timestamp>.zip` back for milestone review. It contains the JSON summary, compiler/run logs, and the exact M0 manifest.
