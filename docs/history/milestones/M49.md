# M49 acceptance candidate — hardening

M49 requires deterministic and repeatable quality gates for:

- SQL parser corpus handling;
- mutation of every protected byte in representative wire and WAL records;
- a durable AUTO_INCREMENT/DECIMAL workload across reopen;
- committed and uncommitted crash-recovery matrix iterations;
- repeated soak execution;
- explicit workload and duration guardrails;
- retained format and protocol compatibility.

The acceptance artifacts include JSON reports from the crash matrix and soak
runner so failures can be reproduced with their exact seed and iteration.
