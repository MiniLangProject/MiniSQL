# M22 acceptance candidate — prepared statements

M22 implements session-local SQL-level `PREPARE`, `EXECUTE ... USING`, and
`DEALLOCATE`, positional `?` markers, exact argument-count checking, constant
AST substitution, schema-generation rebinding, and authorization of the
expanded statement.

M22 is complete only when the cumulative Windows gate prints:

```text
MiniSQL M22-M26R1 acceptance test: SUCCESS
```

and the result JSON marks `M22` as `PASS`.
