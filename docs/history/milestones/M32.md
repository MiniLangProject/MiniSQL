# M32 acceptance candidate: operational client/server applications

M32 addresses the gap between the accepted engine/network worker tests and the
public executables.

The package must pass **72 phases**, including every accepted regression through
M31 and the following new blocks:

1. operational initialization, byte-secret password bootstrap and script helper
   tests;
2. end-to-end use of the real `minisqld.exe --init`, bounded public server and
   `minisql.exe --script` in one transaction-preserving connection;
3. a real persistent `minisqld.exe --serve` process used by public `--ping` and
   `--query` clients without exiting after those clients disconnect;
4. the final cumulative M32 gate.

Required public commands include:

```text
minisqld.exe --init
minisqld.exe --set-admin-password
minisqld.exe --serve
minisqld.exe --serve-authenticated
minisql.exe --shell
minisql.exe --script
```

M32 succeeds only when the test runner ends with:

```text
MiniSQL M32 acceptance test: SUCCESS
```
