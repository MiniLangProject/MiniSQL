# M2 acceptance contract

Status: **accepted by the cumulative M2–M5R2 Windows result (19/19 phases PASS)**.

M2 introduces canonical unsigned LEB128 varints, ZigZag signed varints, CRC-32C and a
checksummed protected-record envelope.

The milestone is accepted only when `test.ps1`:

1. validates the repository and the accepted M1 evidence;
2. recompiles the application and M0/M1 regression gates;
3. passes U32/U64 and I32/I64 golden vectors;
4. completes exhaustive U32 round trips for 0 through 65535;
5. completes deterministic full-width U64 round trips;
6. rejects truncated, non-canonical and overflowing encodings;
7. validates independent CRC-32C reference vectors;
8. detects header and payload corruption in protected envelopes; and
9. marks M2 `PASS`, exits with code 0 and ends with `MiniSQL M2-M5 acceptance test: SUCCESS`.
